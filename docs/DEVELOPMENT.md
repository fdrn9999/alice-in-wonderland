# WONDERLAND — A Liminal Dream

밝고 낯선 카드 미궁을 앨리스와 함께 걷는 **3인칭 3D 탐험 게임**입니다. 첨부 레퍼런스의 색채와 공간 요소를 절차적으로 제작한 입체 지오메트리로 재구성했습니다. 이미지 배경이나 유료 모델을 사용하지 않습니다.

## 실행

Node.js 20.11 이상에서 프로젝트 폴더를 열고 실행합니다. 패키지 설치나 빌드가 필요하지 않습니다.

```sh
npm start
```

브라우저에서 **http://localhost:4173** 을 엽니다. 다른 정적 웹서버에서도 프로젝트 폴더를 그대로 제공할 수 있습니다.

```sh
python -m http.server 4173 --bind 127.0.0.1
```

ES Modules를 사용하므로 `index.html`을 `file://`로 직접 열면 실행되지 않습니다. Three.js **0.180.0**을 jsDelivr CDN에서 가져오므로 인터넷 접속이 필요합니다. Google Fonts 접속이 불가능하면 시스템 글꼴로 표시됩니다. API 키와 계정은 필요하지 않습니다. WebGL2를 지원하는 최신 데스크톱 Chrome/Edge/Firefox를 권장합니다. 터치 전용 이동 조작은 포함하지 않습니다.

## 플레이

**다섯 구역에 하나씩 떠 있는 금빛 카드를 찾아 E로 수집하세요.** 다섯 기억을 모두 모으면 짧은 결말이 열리고 계속 자유 탐험할 수 있습니다. 문은 다른 구역으로 연결되고, 시계와 티파티에도 상호작용할 수 있습니다. 발견한 장소는 지도에서 다시 방문할 수 있습니다.

| 입력 | 기능 |
|---|---|
| W / A / S / D | 카메라 방향을 기준으로 이동 |
| Space | 점프 |
| Shift | 달리기 |
| 마우스 드래그 | 카메라 회전 |
| 마우스 휠 | 카메라 거리 조절 |
| 설정 → 마우스 잠금 | 드래그 없이 마우스 이동으로 회전 |
| ESC | 마우스 잠금 해제 / 열린 대화상자 닫기 |
| E | 기억 수집 / 문 / 시계 / 티파티 상호작용 |
| R | 마지막 체크포인트 복귀 |
| Tab | 지도 열기 / 닫기 |
| M | 환경음 켜기 / 끄기 |
| H | HUD 표시 / 숨기기 |

환경음은 상단 ♪ 버튼으로 켭니다. 오르골·바람·초침·발소리는 Web Audio로 합성합니다. 브라우저 자동 재생 정책에 맞춰 클릭 후 시작합니다. 진행 상황은 `localStorage`에 자동 저장됩니다. 설정의 ‘새로운 꿈 시작’으로 초기화할 수 있습니다.

## 월드

1. **The Infinite Courtyard** — 체커보드 안뜰, 3층 아케이드, 장미 토피어리, 하트 병사.
2. **The Card Soldiers’ Parade** — 네 문양과 A–K 카드로 이루어진 병사들의 정렬. 일부는 천천히 플레이어를 바라봅니다.
3. **The Endless Staircase** — 실제로 오르내리는 36단 계단, 상층 다리와 추가 계단, 공중의 문.
4. **The White Rabbit’s Hall** — 거대한 토끼, 금빛 회중시계와 서로 다른 시각의 시계, 떠 있는 액자.
5. **The Forgotten Tea Party** — 빈 의자와 반복되는 테이블, 금테 찻잔, 공중의 접시.

안뜰의 좌우 다리로 열병장과 티파티에 갈 수 있습니다. 정면 계단을 끝까지 오르면 상층 회랑과 토끼의 홀에 닿습니다. 분홍 문은 공간을 건너뛰는 지름길입니다. 장식용 공중 구조물 중 일부는 연결되어 있지 않습니다.

## 구현과 확장

- `index.html`, `style.css`: 게임 화면, 한글 안내, 지도, 설정, 결말.
- `src/main.js`: 입력, 3인칭 카메라, 카메라 충돌, 수집/체크포인트, 진행 저장, 조명과 약한 Bloom.
- `src/world.js`: 연결된 월드, 절차적 건축/토끼/찻잔, 52종 카드 아틀라스, 240장 InstancedMesh 카드, 병사 시선, 조용한 환경 변화.
- `src/physics.js`: 고정 90Hz 이동, 중력, 점프, AABB와 원형 수평 충돌, 0.38m 자동 계단 오르기, 머리 위 충돌, 추락 복귀.
- `src/character.js`: 지오메트리 기반 앨리스, Idle/Walk/Run/Jump/Fall/Landing 상태와 보행·드레스·머리카락 애니메이션.
- `src/audio.js`: 외부 파일 없는 합성 환경음.

GLB로 교체할 때는 `Alice.root`를 발바닥 위치에 유지하고 `Alice.model`에 정면 +Z, 높이 약 1.9m로 정규화한 모델을 넣습니다. `Alice.update()`에서 상태별 AnimationMixer 클립을 연결하면 이동/물리/카메라 코드는 그대로 사용할 수 있습니다.

정적 오브젝트는 재질과 공간별로 병합해 그리기 호출을 줄이고 화면 밖 구역은 컬링합니다. 모든 재질은 `src/toon.js`의 셀 셰이딩(3단 램프·림 라이트)을 쓰고, `src/post.js`가 깊이·노멀 버퍼에서 잉크 외곽선을 그린 뒤 블룸·그레이딩·Neutral 톤 매핑을 적용합니다. 하늘·대리석·카드 뒷면은 `assets/textures`의 손그림 텍스처이며, 불러오지 못하면 캔버스 대체 텍스처로 그립니다. 성능이 부족하면 설정 → 그래픽 품질 → ‘가벼움’을 선택하세요. 이 모드는 그림자와 외곽선·Bloom 후처리를 끕니다.

## 검증

```sh
npm run check
npm test
```

물리 회귀 테스트: 착지·점프·공중 재점프 방지, 36단 계단 양방향 통과, 지상/공중 벽 충돌, 머리 위 충돌, 추락 복귀, 높은 발판에서의 자연 낙하.

`http://localhost:4173/?diagnostics=1`은 좌표, 구역, 애니메이션 상태, 수집 상태, FPS, 그리기 호출과 삼각형 수를 표시합니다. ‘실제 월드 충돌 경로 검증’은 별도의 물리 바디로 여섯 경로를 검사합니다. `&inspect=0`부터 `&inspect=4`까지 추가하면 해당 기억 근처에서 시작하므로 구역별 그래픽과 상호작용을 점검할 수 있습니다. 이 검사 모드에서도 기억 수집은 진행 상황에 저장됩니다.
